# Moat thesis (recorded 2026-07-06, pre-launch, deliberately)
Analysis is commoditized (any curator has an LLM). The product was never analysis.
1. Independence — buyer literally can't self-supply third-party status; a
   curator citing their own analysis is grading their own homework.
2. Timestamped public track record — "we said → what happened" cannot be
   prompted into existence retroactively. Cadence is the moat; a missed issue
   costs more than a weak one.
3. Private corpus — teardown engagements accrue tapes, servicer reports, curator
   conversations, and an outcomes graph. This becomes the eval set for eventual
   automation (evals-as-IP).
4. Named accountability — a memo a curator can attach to allocator reporting;
   a reputation sink machines can't be.
Testable: the discovery-call moat question in gates.md. If curators say
internal LLM analysis is usable with depositors → early kill signal.
Window risk: same moats available to Particula/Credora/Steakhouse alumni.
Race = who accumulates issues + outcomes + relationships fastest. Ship, don't gild.
