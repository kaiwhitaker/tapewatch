# lesson.md — end-of-day compound prompt (10 min, non-negotiable)

Paste with a 2–5 line summary of what happened today.

---

Compound session. From today's events, produce:

**1. Episodic entry** — memory/episodic/YYYY-MM-DD.md: what happened, factually, ≤8 lines. Include verbatim any customer/prospect language worth keeping (objections, phrasings that landed, questions asked twice).

**2. One lesson (or zero)** — for memory/lessons/: something an agent or future session should know forever. Format: **[domain] — [lesson in one sentence].** Evidence: [one line]. Rule: a real lesson changes future behavior; if today taught nothing new, say "no lesson today" — a lessons file padded with noise is memory rot.

**3. Pipeline deltas** — exact edits to memory/working/pipeline.md, as a diff I can apply.

Nothing else. No motivation, no summary of the summary.
