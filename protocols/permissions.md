# Permission tiers — v1

## AUTO (Claude proceeds freely in-session)
Research, public-API data pulls, metric computation, internal memos, drafting
anything, structural analysis, grading outputs against rubrics.

## CONFIRM (Claude drafts → Kaï edits → Kaï sends/commits/publishes)
All outreach (DMs, emails), Monitor issues, threads/posts, prospect replies,
repo commits, methodology changes, universe-rule amendments.

## NEVER (Kaï only; Claude assembles evidence and recommends)
Published verdicts (CLEAN/WATCH/DRIFT sign-off), pricing, discounts, legal
commitments, LOI language, anything touching Stripe/Mercury/bank credentials
(these never appear in any session), Resolve-adjacent contacts (prohibited
entirely), sending anything.

## Standing security rules
- No GitHub credentials in sessions (trifecta: repo + open web + egress).
- Dune read-only API key: acceptable per-session under Rule of Two.
- Resolve MCP/data: never present in this Project.
- Untrusted web content never enters a session holding any credential.
